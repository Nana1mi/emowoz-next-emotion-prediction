# EmoWOZ Next-Turn Emotion Prediction

任务型对话中的下一轮用户情绪预测：未来语义辅助学习是否有效？

这是一个自然语言处理课程研究项目。在系统回复已经给出、下一句用户文本尚未出现时，利用最近的对话历史预测下一轮用户的情绪。项目比较冻结句向量、JEPA 式未来语义辅助目标、类别不平衡处理、编码器微调、情绪知识蒸馏与角色交互，并使用事后识别诊断和对话级统计分析解释结果。

> 本仓库是代码与汇总结果的公开整理版，不包含原始对话、逐条预测、模型权重或含个人信息的课程报告。它不是 EmoWOZ 官方基准实现，也不是完整 JEPA 或可规划世界模型的复现。

## 任务与信息边界

输入：截至当前系统回复的最近 **6 个话语轮次**，最多 **256 个子词**，超长时保留末尾。输出：下一轮用户情绪的七分类分布。用户首轮不作为预测目标；按官方对话级划分隔离训练、验证和测试。

标签依次为 `neutral`、`fearful`、`dissatisfied`、`apologetic`、`abusive`、`excited`、`satisfied`。处理后训练、验证、测试分别有 **57,240 / 7,409 / 7,534** 个预测样本。所有正式预测模型在测试时均不能读取真实下一句文本或当前情绪真值。

JEPA 式原型在训练时用未来句的冻结 MiniLM 向量提供辅助监督；这不同于在推理时读取未来。使用真实未来文本的实验单独标记为 **事后诊断**。

## 核心结果

官方测试集七类 Macro-F1，单位为百分比；`±` 是种子 42、43、44 的样本标准差，**不是置信区间**。

| 实验条件 | Macro-F1 (%) | 解释 |
| --- | ---: | --- |
| 冻结历史句向量分类器（原始/控制轮） | 27.03 ± 0.50 | 轻量历史预测基线 |
| 原始 JEPA 式辅助目标 | 27.07 ± 0.47 | 冻结编码器 |
| 残差 + 多正例对比辅助目标，权重 1.0 | 27.49 ± 0.08 | 分类收益有限 |
| 同轮冻结 MiniLM（编码器对照轮） | 27.24 ± 0.26 | 与下面微调模型匹配比较 |
| MiniLM 最后两层微调 | 31.21 ± 1.05 | 任务适配 |
| MiniLM 全量微调 CE | **31.94 ± 0.51** | 已完成预测设置中最高的三种子均值 |
| 全量微调 + 情绪 KD | 31.71 ± 0.38 | 验证选择的蒸馏配置 |
| 同容量全局分类头 | 31.82 ± 0.39 | 角色实验对照 |
| 角色加性融合 | 30.76 ± 0.56 | 验证选择的角色配置 |
| 角色 FiLM | 31.36 ± 0.76 | 同一次上下文编码后的角色池化交互 |
| 真实下一句单独分类 | 53.08 ± 1.01 | **事后识别，不是前瞻预测** |
| 历史 + 真实下一句 | 51.88 ± 1.22 | **事后诊断** |
| 历史重复拼接 | 27.38 ± 0.24 | 事后拼接实验的同维度对照 |

不同实验轮的冻结模型实现和训练细节不同，27.03 与 27.24 不应混作同一个对照。原始情绪保持基线使用真实当前情绪，属于 oracle 诊断，不是可直接部署的文本模型。

### 从现有证据能说什么？

- **任务适配是本项目最清晰的正面结果。** 同轮全量微调比冻结 MiniLM 高 4.70 个百分点；以三个已训练模型为条件，对话 bootstrap 的配对 95% 区间约为 [3.40, 6.18] 个百分点。
- **语义检索改善没有稳定转化为情绪分类收益。** 抽样候选池 Recall@10 从 3.47% 提高到 8.80%，但对应 Macro-F1 改善约 0.46 个百分点，配对区间覆盖零。检索指标不等于情绪信息质量。
- **KD 与角色 FiLM 尚未显示额外稳定收益。** 这不等价于证明这些方法无效，也不代表微调编码器上的 JEPA 已经被否定：后者没有在本项目中完成。
- **前瞻预测与事后识别存在明显差距。** 真实未来文本诊断不能视作预测成绩或理论上限；输入结构和任务难度也发生了变化。
- **稀有类结论受到样本量限制。** 测试集 fearful 仅 16 条，abusive 仅 17 条；零命中不能证明该类别本质不可预测。

统计补充审计覆盖 28 种配置、84 份对齐预测，使用 10,000 次对话 bootstrap 和 10,000 次对话配对置换，主比较做 Holm 校正。这是既有官方测试预测的探索性审计，**没有完成全数据交叉验证、新种子扩展、功效分析或等效性检验**。

## 快速开始

推荐 Python 3.11。先按设备安装兼容的 PyTorch，再安装其余依赖；已有可用 GPU 环境不必重新安装 PyTorch。

```powershell
conda activate kg_project
python -m pip install -r requirements.txt
python run_experiments.py smoke --device cpu
```

上述 `smoke` 仅使用合成样本，不产生真实实验指标。完整实验需联网下载 EmoWOZ 和模型，按 [复现说明](docs/reproduction.md) 分阶段执行。直接打开 [results/](results/) 即可查看已有汇总，不需要重新训练。

# 公开整理范围

本次只整理和发布已有成果，没有重新训练、改变实验结果或修改课程报告。

## 包含

- 17 个原样保留的训练、诊断、演示和核验 Python 文件。
- 5 个移除个人机器 Python 绝对路径的 PowerShell 入口。
- 六轮正式实验的 `summary.json`、数据分布统计、报告所用数值提取，以及全体和分来源统计审计结果。
- 任务说明、结果解释、复现步骤和对话级统计方法。

JSON 内指标保留原值与原 schema；正文结果统一明确百分比、百分点、种子标准差与对话置信区间的区别。统计方法说明中的原输出目录名属于历史记录；本公开版对应结果位于 `results/statistics_*.json`。

## 不包含

- 原始数据、处理后对话文本、含文本的逐条预测或错例。
- 预训练权重、训练检查点、优化器状态、embedding 缓存。
- 含姓名、学号的课程报告、封面和 LaTeX 工程。
- 机器日志、登录信息、令牌、个人绝对路径或其他项目的文件。
- 历史聊天和第三方模型建议；它们不是已验证实验结论。

仅聚合结果不足以独立复算所有统计检验。需要验证逐条结果时，按复现流程从官方数据重建本地完整输出。

## 结果文件

`results/*_summary.json` 分别对应原始基线、控制变量、事后诊断、编码器适配、蒸馏和角色交互。`report_extract.json` 是课程报告使用的逐种子及聚合数值提取，不含对话文本。`statistics_all.json` 是官方测试集审计；`statistics_multiwoz.json` 与 `statistics_dialmage.json` 是混合来源训练后的来源子集诊断，**不是跨来源迁移测试**。

当前没有新增全数据交叉验证、5–10 种子扩展、正式功效分析、微调编码器上的 JEPA、EMA 目标编码器、桥接实验、人类前瞻标注或反事实系统动作实验。不能把这些后续设想写成已完成工作。

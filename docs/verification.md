# 发布前核验

公开整理时在原 Windows `kg_project` 环境做检查，不启动正式训练或重跑统计审计。

- 17 个 Python 源文件通过语法解析，并逐字节核对与原工程一致。
- 5 个 PowerShell 启动入口通过语法解析；仅当前 Python 环境定位方式经过可移植性调整。
- 11 个结果 JSON 与原输出逐字节一致；公开 JSON 不含历史对话、真实未来文本等逐条字段。
- 对上传文件扫描个人绝对路径、课程报告姓名学号及常见令牌格式；没有发现匹配。此检查是有限的发布前防护，不是安全审计认证。
- CPU smoke、控制变量、事后诊断、可训练编码器、KD 和角色交互使用合成数据验证。统计核验中需要完整历史输入的项目在精简公开目录中会跳过，应与实际执行输出一起阅读。

## 保留的已知自检问题

`verify_downloader.py` 在本机一次运行中：故意截断连接后，下载器成功重试，最终文件与测试 payload 逐字节一致且通过 JSON 校验；但用例要求断点恢复的起点严格等于 1024 字节，实际断连时未能落盘这 1024 字节，从 0 重试，因此 `resume_seen` 断言失败。该严格偏移断言在本次环境未通过，不能据此宣称断点续传自检全部通过。

没有为发布修改下载器或测试用例，也没有改写任何历史实验指标。正式下载仍有大小、范围和 JSON 完整性检查；若读者遇到网络问题，可以从作者页面手工下载到 `data/raw/`。
